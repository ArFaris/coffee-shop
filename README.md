# Coffee Shop Project

Интерактивный веб-сайт магазина кофе с полноценной корзиной покупок, пагинацией и адаптивным интерфейсом. Проект демонстрирует подходы к организации кода на чистом JavaScript без использования фреймворков.

## Ссылки

- **Демо (GitHub Pages):** [https://arfaris.github.io/coffee-shop/](https://arfaris.github.io/coffee-shop/)

---

## Функциональность

- **Каталог товаров** — две секции с разными типами товаров (горизонтальная и вертикальная)
- **Корзина покупок** — добавление/удаление товаров, изменение количества, подсчет итоговой суммы
- **Пагинация** — постраничное отображение товаров в вертикальной секции
- **Адаптивное меню** — бургер-меню на мобильных устройствах
- **Модальное окно корзины** — открытие/закрытие с оверлеем
- **Сохранение состояния** — корзина сохраняется в `localStorage` при перезагрузке страницы
- **Кнопка прокрутки** — плавный скролл к началу страницы

## Архитектура проекта

### Frontend (JavaScript)

Приложение построено на **классовом MVC-подходе** с разделением ответственности:

| Класс | Ответственность |
|-------|-----------------|
| `MenuManager` | Управление мобильным меню (бургер), оверлей, закрытие по Escape |
| `CartManager` | Управление модальным окном корзины (открытие/закрытие) |
| `CartDataManager` | Логика корзины: добавление, удаление, изменение количества, `localStorage` |
| `PaginationManager` | Пагинация товаров в вертикальной секции |


## Структура проекта (CSS)

В проекте реализована модульная архитектура стилей. Основные файлы расположены в директории `src/styles`:

### 1. Base (`/base`)
Базовые настройки, которые применяются ко всему проекту:
* `variables.css` — Глобальные CSS-переменные (цвета, шрифты, размеры).
* `reset.css` — Сброс стандартных стилей браузера.
* `fonts.css` — Подключение и настройка шрифтов.
* `base.css` — Общие стили для тегов (body, links).

### 2. Components (`/components`)
Изолированные стили для переиспользуемых мелких элементов интерфейса:
* `Buttons/` — Стили кнопок.
* `CoffeeCard/` — Карточки товаров.
* `TitleArea/` — Оформление заголовков и текстовых блоков.
* `CoffeeLine/`, `Footer/`, `HeaderNav/` и др.

### 3. Sections (`/sections`)
Стили для крупных блоков страницы:
* `BaseInfo/` — Информационный блок.
* `CoffeeSection/` — Секция с ассортиментом кофе.
* `GiftsetSection/` — Подарочные наборы.

### 4. Utils & Entry Point
* **`utils/animations.css`** — Описание ключевых кадров (`keyframes`) и вспомогательных классов для анимации.
* **`main.css`** — Главный файл, который импортирует в себя все модули (точка входа).
